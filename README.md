Leonida Legends is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI, with a cited guide for every trophy, a six-stage roadmap to the platinum, missable flags, and a checklist that saves progress in the browser. Open it in any browser with the network off — it loads nothing from outside its own files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
