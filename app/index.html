      About this guide

      Names, descriptions and grades are the official PlayStation trophy list, shown exactly as published. Every guide is written in our own words for this guide, built from those descriptions, and each one names its sources — the official PlayStation trophy list, Exophase and PSNProfiles — so you can check where each fact comes from. No guide text is copied from another guide. The game was not yet released when this guide was written, so where the official description is the only source, the guide says so and sticks to what the description supports.

      Missable means the trophy is tied to a one-time moment or a specific setup that is easy to walk past; each missable trophy carries a note explaining why. Story mission trophies are not missable — missions can be replayed. This guide is an independent fan-made tracker. It uses no Rockstar logo, artwork, box art or game screenshots; the look is its own.
